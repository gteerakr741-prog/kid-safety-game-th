# คิดก่อนเลือก: ภารกิจพิทักษ์ตัวเอง

เกม AR สำหรับเด็กอายุ 7–9 ปี ฝึกคิดและเลือกวิธีตอบสนองต่อสถานการณ์เสี่ยง โดยยึดหลัก:

- ไม่รับ
- ไม่ลอง
- ไม่ไป
- บอกผู้ใหญ่ที่ไว้ใจ

## เล่นออนไลน์

[เปิดเกมคิดก่อนเลือก](https://gteerakr741-prog.github.io/kid-safety-game-th/)

![QR Code สำหรับเปิดเกม](./qr-code.png)

## วิธีเปิด

เปิดผ่านเว็บเซิร์ฟเวอร์เพื่อให้กล้องทำงาน เช่น:

```powershell
python -m http.server 4181 --bind 127.0.0.1
```

จากนั้นเปิด `http://127.0.0.1:4181/` ในเบราว์เซอร์ ลิงก์ทดสอบแบบปิดเสียงใช้ `?sound=off` และปิดเสียงอ่านใช้ `?voice=off`

## การควบคุม

- ชี้นิ้วค้างบนคำตอบประมาณ 2 วินาที
- เมื่อมีหลายมือ ระบบจะเลือกมือของผู้เล่นที่อยู่ใกล้กล้องที่สุด
- แตะหรือคลิกคำตอบได้
- กด `1` หรือ `2` บนคีย์บอร์ดได้
- กด `Esc` เพื่อหยุดพัก และกด `Enter` หรือ `Space` เพื่อเล่นต่อ

## เนื้อหา

มี 12 สถานการณ์ ครอบคลุมบุหรี่ไฟฟ้า ของกินและยาที่ไม่ทราบที่มา คนแปลกหน้า ความกดดันจากเพื่อน ความลับที่อันตราย การนัดพบคนออนไลน์ และการขอความช่วยเหลือฉุกเฉิน ตำแหน่งคำตอบปลอดภัยจะสลับซ้ายขวาทุกข้อ

## ไฟล์สำคัญ
